💾 WHAT THE SYSTEM DOES
================================================================================

1. REGISTRATION PHASE
   - Admin creates account
   - Admin registers employees with photos
   - System extracts face recognition data
   - Face descriptors stored in database

2. SCANNING PHASE
   - Employee scans face
   - System detects and recognizes face
   - Automatically records Time In or Time Out
   - Generates attendance record

3. TRACKING PHASE
   - System stores attendance records
   - Calculates hours worked
   - Detects late arrivals
   - Tracks overtime/undertime

4. REPORTING PHASE
   - Admin views attendance records
   - Generates daily/weekly/monthly reports
   - Exports to CSV
   - Reviews statistics and trends

================================================================================
📞 COMMON ISSUES & QUICK FIXES
================================================================================

Issue: Blank page
Fix: Press F12, check console for errors

Issue: Cannot login
Fix: Check Firebase auth is enabled, verify credentials

Issue: Face not recognized
Fix: Better lighting, clear photo, try again

Issue: Camera not working
Fix: Check browser permissions, try different browser

Issue: Firebase connection error
Fix: Check config.js credentials, verify internet connection

Issue: File upload failed
Fix: Check file size <5MB, verify internet

Issue: No records showing
Fix: Check date filter, click "Reset"

For more help, see: SETUP_GUIDE.md (Troubleshooting section)
